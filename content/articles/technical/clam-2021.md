# CLAM — Data-efficient and Weakly Supervised Computational Pathology on Whole-Slide Images

{{ article("clam-2021") }}

{{ local_graph("clam-2021") }}

## Why it matters

CLAM is the **most-cited and most-deployed weakly-supervised MIL framework** in pathology in 2021–2025. Two reasons:

1. It produces **reliable accuracy** on slide-level classification across many cancer subtype and detection tasks while being simpler and faster than later Transformer-based aggregators.
2. The **open-source pipeline** at `mahmoodlab/CLAM` covers the entire WSI workflow: tissue segmentation, patch extraction, feature extraction (any backbone), MIL training, and attention-heatmap generation. It is the toolkit that other PFM evaluations are built on.

Modern PFM benchmarks (UNI, GigaPath, Virchow) commonly run "PFM features → CLAM head" as their default MIL evaluation.

## Core idea

CLAM extends {{ node_link("abmil") }} along two axes:

1. **Per-class attention branches** (CLAM-MB): one attention map per class instead of one shared map. CLAM-SB keeps a single attention map and a slide-level softmax — usually adequate for binary tasks.
2. **Instance-level clustering loss**: highest-attended patches per class are positive pseudo-labels for an auxiliary classifier; lowest-attended are negative. This regularises attention and improves data efficiency when slide counts are small (a few hundred per class).

## Inputs and outputs

- **Input**: bag of patch features per WSI (from any encoder — ResNet-50 / CTransPath / UNI / GigaPath).
- **Output**: slide-level class probabilities + per-class attention heatmaps (interpretable lesion localisation as a free byproduct).

## Datasets / tasks / metrics

- **Renal cell carcinoma** subtyping (TCGA-RCC).
- **Non-small cell lung cancer** subtyping (TCGA-NSCLC).
- **Breast cancer metastasis** detection ({{ node_link("camelyon16") }}).
- Metrics: AUC, accuracy, F1.

## Method

- Patch features from ResNet-50 ImageNet (original) or any modern PFM (current practice).
- Per-class attention MLPs → per-class bag embeddings → per-class scores.
- Instance-clustering loss with attention-derived pseudo-labels.
- Adam, dropout, standard end-to-end training.

## Main results

CLAM outperforms ABMIL, MIL-RNN, and mean / max pooling on all three tasks. Data-efficiency ablations show ~70% AUC with as few as 100 training slides — a meaningful threshold for rare-subtype studies.

## Beyond standard benchmarks

A distinguishing claim of the paper — and one the authors emphasise in the abstract — is that CLAM **generalises beyond the standard benchmark distribution**:

- **Independent test cohorts** — models trained on TCGA transfer to non-TCGA institutional cohorts without retraining.
- **Smartphone microscopy** — predictions hold up on slides imaged via consumer smartphone optics rather than research-grade scanners.
- **Varying tissue content** — robust to biopsies / resections with different amounts of useful tissue per slide.

These results frame CLAM as a **domain-adaptation-ready** weak-supervision pipeline, not just an accuracy-on-clean-benchmarks improvement over ABMIL.

## Limitations

- **Permutation-invariant** — no spatial modelling beyond patch features (see {{ node_link("transmil") }} for a sequence-aware alternative).
- **Pseudo-labels can be noisy** in tumour-rich slides where both top- and bottom-attended patches contain tumour.
- **Original backbone is dated** — modern accuracy gain comes mostly from upgrading the patch encoder (UNI / GigaPath / Virchow).
