# 基于全切片图像弱监督深度学习的临床级计算病理

{{ article("campanella-2019") }}

{{ local_graph("campanella-2019") }}

## 为什么重要

这篇 Nature Medicine 2019 论文**在规模上、在临床工作流中**论证了：WSI 上的弱监督 MIL 无需逐块标注即可可行。队列为 Memorial Sloan Kettering Cancer Center 三大器官系统约 44,732 张 WSI：

- **前列腺**穿刺活检 —— 24,859 张切片
- **基底细胞癌（BCC）**皮肤活检 —— 9,962 张切片
- **乳腺癌转移**至腋窝淋巴结 —— 9,894 张切片

标签仅为**切片级诊断报告** —— 没有像素或块级标注。MIL 流水线（CNN 特征提取器 + RNN 聚合器）在全部三项任务上均取得 AUC > 0.98。论文随后定义了一种**计算机辅助分诊工作流**：模型将切片标记为阳性 / 阴性；病理学家审查阳性切片以及一部分抽样的阴性切片。建模显示可安全排除 65–75% 的已确认阴性切片。

这是**临床级规模先例**，激励了之后几乎所有的病理 MIL 论文。

## 核心思路

- 切片级标签从临床诊断报告中挖掘。
- 逐切片 MIL 训练：CNN 编码器 + 带 top-k 实例选择的 RNN 聚合器。
- 在内部 MSKCC 算力上进行大规模分布式训练。
- 校准操作点以匹配**临床分诊**目标（高敏感性、对阴性排除可接受的特异性）。

## 临床视角

| 维度 | 详情 |
|--------|--------|
| 临床问题 | 常规外科病理的诊断分诊 —— 前列腺 / BCC / 乳腺腋窝 |
| 队列设计 | MSKCC 回顾性队列，切片级标签源自临床报告 |
| 临床工作流 | AI 分诊：病理学家审查 AI 阳性 + 抽样的阴性 |
| 临床终点 | 癌症存在检测的 AUC；在高敏感性下的安全排除比例 |
| 临床 AI 需求 | 工作负载瓶颈 + 早期癌症检测中观察者间差异 |

## 数据集 / 任务 / 指标

- 内部 MSKCC 队列（无法释出）。
- 任务：前列腺活检、BCC 皮肤活检、乳腺腋窝淋巴结的切片级肿瘤检测。
- 指标：AUC、敏感性、特异性、在固定敏感性下的安全排除比例。

## 方法

- ResNet 风格的 CNN 特征提取器。
- 带 top-k 实例选择的基于 RNN 的 MIL 聚合器。
- 袋-实例挖掘以应对 gigapixel 级袋尺寸。
- 切片级交叉熵 + 临床分诊校准。

## 主要结果

全部三项任务 AUC > 0.98。分诊工作流可在满敏感性下安全排除 65–75% 的已确认阴性切片，显著节省病理学家时间。

## 局限

- **内部 MSKCC 数据** —— 从零开始的外部复现不可能。
- **RNN 聚合器已被替代** —— 注意力 / Transformer MIL（{{ node_link("abmil") }} / {{ node_link("clam") }} / {{ node_link("transmil") }}）后来居上。
- **回顾性** —— 临床级主张最终需要前瞻性部署研究来支撑。
