# A Multimodal Whole-Slide Foundation Model for Pathology

{{ article("titan-2025") }}

{{ local_graph("titan-2025") }}

## Why it matters

{{ node_link("gigapath-2024") }}, {{ node_link("chief-2024") }}, and {{ node_link("virchow-2024") }} are **vision-only** PFMs — they produce slide / patch embeddings without any text alignment. {{ node_link("conch-2024") }} adds vision-language at the patch level only. **TITAN closes the gap**: it is the first widely-cited **multimodal whole-slide foundation model** that aligns slide embeddings with paired pathology reports + LLM-generated captions, supporting zero-shot slide-level classification, slide-text retrieval, and slide-level report generation in one model.

## Core idea

```
WSI patch sequence → CONCH/UNI-style patch encoder → patch features
                          ↓
                  slide-level Transformer
                          ↓
            slide embedding ←  contrastive  →  report embedding (text Transformer)
                                                          ↑
                                              clinical reports
                                              + LLM-generated captions
```

The slide encoder is contrastively aligned with both real clinical reports and synthetic captions generated by a large language model — the synthetic-caption augmentation expands the effective text supervision substantially.

## Inputs and outputs

- **Input**: WSI patch sequence + pathology text prompt.
- **Output**: slide embedding, text embedding, generated caption, slide-level class probabilities.

## Datasets / tasks / metrics

- **Pretraining**: Mahmood-Lab-internal multimodal slide-report cohort.
- **Downstream**: pan-cancer subtyping, biomarker prediction, mutation prediction, survival, slide-text retrieval, report generation, rare-cancer detection.
- Metrics: AUC, balanced accuracy, top-k accuracy, C-index, ROUGE / BLEU for captioning.

## Method

- **Patch encoder**: CONCH/UNI-style ViT.
- **Slide encoder**: slide-level Transformer.
- **Text encoder**: text Transformer.
- **Training**: contrastive alignment with reports + synthetic LLM captions.

## Main results

TITAN matches or exceeds {{ node_link("gigapath-2024") }} / {{ node_link("chief-2024") }} / {{ node_link("virchow-2024") }} on most slide-level downstream tasks while adding zero-shot vision-language capabilities those models lack.

## Limitations

- **Pretraining cohort partly internal** — full reproduction blocked.
- **Synthetic-caption quality** depends on the upstream LLM.
- **Slide-level Transformer** adds inference cost over patch-only PFMs.
- **Gated weights** via Mahmood Lab on Hugging Face.
