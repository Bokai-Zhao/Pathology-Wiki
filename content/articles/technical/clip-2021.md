# Learning Transferable Visual Models from Natural Language Supervision

{{ article("clip-2021") }}

{{ local_graph("clip-2021") }}

## Why it matters

CLIP is **not** a pathology paper, but it is the **architectural foundation of every modern pathology vision-language model**. PLIP, CONCH, QuiltNet, MUSK, and MI-Zero are all CLIP-architecture or CLIP-initialised models fine-tuned on pathology data. Any pathology VL discussion that doesn't reference CLIP is incomplete.

The contribution is **scale + simplicity**: a dual-encoder (image + text), an InfoNCE contrastive objective, 400M (image, caption) pairs scraped from the web. The result is a model that does **zero-shot image classification** by encoding candidate class names as text and picking the closest text to the image — without seeing a single labelled image.

## Core idea

```
image batch → image encoder → I (B, D)
text batch  → text encoder  → T (B, D)
similarity matrix S = I · T.T  → diagonal positives, off-diagonal negatives
loss = cross-entropy on rows (img→txt) + cross-entropy on cols (txt→img)
```

At inference, zero-shot classification:

```
prompt_k = template.format(class_name_k)
text_emb_k = text_encoder(prompt_k)
prob(class_k | image) ∝ exp(<image_emb, text_emb_k>)
```

## Inputs and outputs

- **Input**: RGB image + text prompt.
- **Output**: image embedding, text embedding, zero-shot class probabilities.

## Datasets / tasks / metrics

- Pretraining: WIT (WebImageText) — 400M (image, caption) pairs scraped from the web (OpenAI-internal, not released).
- Evaluation: 27+ benchmarks including ImageNet, CIFAR, Birdsnap, Food101, etc.
- Metrics: top-1 / top-5 accuracy in zero-shot, linear-probe, and full fine-tuning settings.

## Method

- **Image encoders**: ResNet-50/101/RN50x4/RN50x16/RN50x64 + ViT-B/32, ViT-B/16, ViT-L/14.
- **Text encoder**: 12-layer Transformer (similar to GPT-2 small).
- **Loss**: symmetric cross-entropy on the similarity matrix.
- **Training**: large batch (~32k), mixed-precision, ~14 days on hundreds of GPUs.

## Main results

CLIP zero-shot matches or exceeds supervised ResNet-50 on ImageNet without seeing any ImageNet training images. Across 27 datasets, zero-shot CLIP is competitive with fully-supervised baselines. The release of code + weights (ViT-B/32, ViT-B/16, ViT-L/14, RN50, RN101, etc.) sparked the entire VLM era.

## Limitations

- **Pretraining data not released** — reproduction needs LAION or similar.
- **Natural-image + web-text domain** — direct application to pathology fails without fine-tuning ({{ node_link("plip-2023") }}, CONCH).
- **Prompt-engineering sensitivity** — small prompt changes shift accuracy.
- **No clinical text training** — medical / pathology terminology is out-of-distribution.
