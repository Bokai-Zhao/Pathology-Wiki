{{ article("clip-2021") }}

{{ local_graph("clip-2021") }}

## 为什么重要

CLIP **不是**一篇病理论文，但它是**每个现代病理视觉-语言模型的架构基础**。PLIP、CONCH、QuiltNet、MUSK、MI-Zero 都是 CLIP 架构或 CLIP 初始化的模型，再在病理数据上微调。任何不引用 CLIP 的病理 VL 讨论都是不完整的。

它的贡献是**规模 + 简洁**：一个双编码器（图像 + 文本）、一个 InfoNCE 对比目标、4 亿条从网络抓取的（图像，文本说明）对。结果是一个能够进行**零样本图像分类**的模型 —— 将候选类名编码为文本、选取距离图像最近的文本 —— 而无需见过哪怕一张有标注的图像。

## 核心思路

```
image batch → image encoder → I (B, D)
text batch  → text encoder  → T (B, D)
similarity matrix S = I · T.T  → diagonal positives, off-diagonal negatives
loss = cross-entropy on rows (img→txt) + cross-entropy on cols (txt→img)
```

推理时，零样本分类：

```
prompt_k = template.format(class_name_k)
text_emb_k = text_encoder(prompt_k)
prob(class_k | image) ∝ exp(<image_emb, text_emb_k>)
```

## 输入与输出

- **输入**：RGB 图像 + 文本提示。
- **输出**：图像嵌入、文本嵌入、零样本类概率。

## 数据集 / 任务 / 指标

- 预训练：WIT（WebImageText）—— 4 亿条从网络抓取的（图像，文本说明）对（OpenAI 内部，未公开）。
- 评估：27+ 基准，包括 ImageNet、CIFAR、Birdsnap、Food101 等。
- 指标：零样本、线性探针与完整微调设定下的 top-1 / top-5 准确率。

## 方法

- **图像编码器**：ResNet-50/101/RN50x4/RN50x16/RN50x64 + ViT-B/32、ViT-B/16、ViT-L/14。
- **文本编码器**：12 层 Transformer（类似 GPT-2 small）。
- **损失**：在相似度矩阵上的对称交叉熵。
- **训练**：大批量（约 32k）、混合精度、在数百块 GPU 上训练约 14 天。

## 主要结果

CLIP 在没有见过任何 ImageNet 训练图像的情况下，零样本即可与 ImageNet 上有监督的 ResNet-50 持平或超越。跨 27 个数据集，零样本 CLIP 与完全监督基线具有竞争力。代码 + 权重的释出（ViT-B/32、ViT-B/16、ViT-L/14、RN50、RN101 等）点燃了整个 VLM 时代。

## 局限

- **预训练数据未公开** —— 复现需要 LAION 或类似数据。
- **自然图像 + 网页文本域** —— 直接应用到病理在不微调（{{ node_link("plip-2023") }}、CONCH）的情况下会失败。
- **对提示工程敏感** —— 小的提示变动会改变准确率。
- **无临床文本训练** —— 医学 / 病理术语处于分布外。
