# 利用医学 Twitter 的病理图像分析视觉-语言基础模型

{{ article("plip-2023") }}

{{ local_graph("plip-2023") }}

## 为什么重要

在 PLIP 之前，病理视觉-语言工作较为零散：小型字幕数据集（ARCH）、在自然图像上预训练的 CLIP 直接套用、有限语料上的临时图文模型。PLIP 是**首个被广泛引用的、开放权重的病理视觉-语言基础模型**，并随其发布 **OpenPath 数据集** —— 约 20 万条从医学 Twitter（临床医生使用病理相关标签发布的内容）挖掘的病理图文对 —— 这是首个大规模公开的病理图文语料。

PLIP 启用了首批**零样本病理图像分类流水线**，如今已成为病理 VL 领域标准的开源权重参考。

## 核心思路

- 取 {{ node_link("clip-2021") }} ViT-B/32。
- 从医学 Twitter 挖掘约 20 万条病理图文对 —— OpenPath 语料。
- 用标准 InfoNCE 在 OpenPath 上微调 CLIP。
- 释出权重 + 数据集。

## 输入与输出

- **输入**：H&E 块 + 病理文本提示。
- **输出**：图像嵌入、文本嵌入、零样本类概率。

## 数据集 / 任务 / 指标

- **预训练**：OpenPath（约 20 万条来自医学 Twitter 的病理图文对）。
- **下游评估**：Kather CRC、{{ node_link("pannuke") }} patch crops 等。
- 指标：零样本准确率、top-k 检索、precision-at-k。

## 方法

- 架构：CLIP ViT-B/32 + 文本 Transformer。
- 训练：在（图像，文本说明）对上施加 InfoNCE。
- 推理：文本提示 → 在共享嵌入空间上通过点积得到零样本类概率。

## 主要结果

PLIP 在多个病理零样本基准上优于 CLIP-ImageNet，并在无逐任务标签的情况下与多个有监督基线持平或超越。图文检索在病理语料上工作良好。

## 局限

- **Twitter 标题含噪** —— 临床保真度参差不齐。
- **ViT-B/32 骨干较小**，按现代 PFM 标准衡量 —— 较新的病理 VLM（CONCH、QuiltNet）使用更大的编码器与更精选的语料。
- **常见所见偏置** —— Twitter 内容偏向常见所见，稀有病况欠表征。
- **仅块级** —— 切片级零样本需要 {{ node_link("mi-zero-2023") }} 或 CONCH-MIL。
- **伦理 / 知情同意疑虑** —— Twitter 挖掘数据；后续 VLM（CONCH、QuiltNet）转向教科书来源以规避此问题。
