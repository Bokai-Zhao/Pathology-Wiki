# 2026-05-20 — add-tcga

Five-artifact ingestion of TCGA (The Cancer Genome Atlas) as a dataset node. **Long-overdue**: TCGA was referenced as a `to_verify` hint by 6+ existing nodes since cluster 3 (CTransPath / Phikon / TANGLE / MCAT / PORPOISE / DSMIL / DTFD-MIL / etc.). This single addition resolves the largest cluster of pending dataset hints in the graph.

## Warnings

- **Exact slide / patient counts marked `to_verify`** — TCGA scale shifts as the GDC re-indexes; ~30k WSIs / ~11k patients is a snapshot estimate.
- **Per-cohort sub-datasets** (TCGA-BRCA, TCGA-LUAD, TCGA-RCC, TCGA-NSCLC, TCGA-PRAD, TCGA-COAD, ...) intentionally NOT promoted to separate nodes — they're aliases / subsets of `tcga` and would balloon the graph without much added structure. Future per-cohort dataset nodes only if a paper specifically requires the sub-cohort distinction.
- **`weinstein-2013-tcga-pan-cancer`** flagship paper is referenced as a hint but not yet ingested — listed as a pending reference.
- **dbGaP controlled-access fields** are mentioned in YAML / SKILL but not modelled as a separate access tier.
