    ABMIL — Attention-Based Multiple Instance Learning¶

    method

    Attention-Based Multiple Instance Learning (ABMIL)¶

    stage: deep_wsi_learning · parents: weakly-supervised-mil

    Replace permutation-invariant pooling (mean / max) over instances with a learned attention mechanism. Each instance produces a scalar attention weight via a small two-layer MLP; the bag embedding is the attention-weighted sum of instance embeddings. The attention weights are interpretable — they highlight which patches drove the slide-level prediction, providing free heatmap-style localisation.

    Local graphmethodarticledataset1 out · 4 in · 5 neighbours

    Why it matters¶

    Before ABMIL, MIL pooling was dominated by mean and max — both fixed and uninformative. ABMIL introduced a learned scalar attention weight per instance, parameterised by a small two-layer MLP. The bag embedding becomes the attention-weighted sum of instance embeddings:

    α_k = softmax(w^T tanh(V h_k))
bag_emb = Σ_k α_k * h_k

    This is permutation-invariant (still satisfies the MIL assumption) but trainable (the model can up-weight informative patches). The attention weights are interpretable — they yield free heatmap-style localisation of which patches drove the slide-level prediction. Every modern MIL variant (CLAM — Clustering-constrained Attention MIL, TransMIL — Transformer-based Correlated MIL, DSMIL, DTFD-MIL) descends from ABMIL.

    Core idea¶

    • Two-layer MLP over instance embeddings produces a scalar weight per instance.
    • Vanilla vs gated attention: gated multiplies the attention pre-activation by a separate sigmoid gate, which can improve calibration on harder bags.
    • Bag embedding = attention-weighted sum.
    • Classifier on top of the bag embedding.

    Key questions¶

    • Sigmoid vs softmax attention?
    • Gated attention vs vanilla — gain depends on bag size and class boundary.
    • Attention temperature / scaling — affects heatmap sparsity.
    • Single-head vs multi-head for multi-class bags? (Multi-head leads to CLAM — Clustering-constrained Attention MIL-MB.)

    Representative article¶

    • ABMIL (Ilse, Tomczak, Welling 2018) — Ilse, Tomczak, Welling, ICML 2018.

    Limitations¶

    • Permutation-invariant — ignores patch positions in the slide. Spatial structure must come from elsewhere.
    • No instance-instance interaction — each instance is scored in isolation. TransMIL — Transformer-based Correlated MIL addresses this.
    • Single-class attention — multi-class extensions (CLAM-MB) need per-class branches.

    source

    ABMIL is the default first baseline for any new WSI slide-level classification task. If a method paper does not include an ABMIL number, it is suspicious. Pair with Camelyon16 — Cancer Metastases in Lymph Nodes 2016 for a sanity check.
